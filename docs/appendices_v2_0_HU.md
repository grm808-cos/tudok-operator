# TUDOK Operator v2.0 - Mellékleti és nyílt validációs csomagtérkép

Ez a fájl az aktuális publikus repository-anyagokat rendeli hozzá a v2.0 metodológiai tanulmány mellékleti funkcióihoz (DOI: 10.5281/zenodo.22916404).

## Csomagtérkép

- **A melléklet - Részletes C/K/I/D pontozási rubrika:** `protocol/ckid_rubric.md`
- **B melléklet - Pilotdemonstráció és számítási példa:** `pilot/pilot_design.md`, kezdeti pilotfájlok
- **C melléklet - Fix TUDOK evaluator protokoll:** `protocol/evaluator_prompt_HU.md`, `protocol/evaluator_prompt_EN.md`
- **D melléklet - Strukturált reporting JSON séma:** `protocol/reporting_schema.json`
- **E melléklet - Diagnostic flag szótár:** `protocol/diagnostic_flags.md`
- **F melléklet - Inter-rater agreement protokoll:** `pilot/irr_report_template.csv`
- **G melléklet - Robusztusság és érzékenységvizsgálat:** `pilot/prompt_set_template.csv`, `pilot/scoring_template.csv`
- **H melléklet - Mini pilot validációs terv:** `pilot/pilot_design.md`
- **I melléklet - Domain-specifikus adaptáció:** rubrika + diagnostic flag anyagok
- **J melléklet - Részletes példagyűjtemény:** `examples/`
- **K melléklet - Ábralista és diagram-kísérőanyagok:** `figures/`
- **L melléklet - Etikai és transzparencia nyilatkozat:** elsődleges tanulmány és repository-határállítások
- **M melléklet - Nyílt validációs és licencmegjegyzés:** `LICENSE.md`
- **N melléklet - GitHub repository és open validation package:** jelen repository

## Státusz

Pilot-ready / pre-validation / open-evaluation. Az anyagok független tesztelést és szakértői review-t támogatnak; nem jelentenek tanúsítást vagy empirikus igazságbizonyítást.
