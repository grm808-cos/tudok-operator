# TUDOK Operator v0.4 - Appendix Package

This document is the index of the appendix package for the public pre-validation TUDOK protocol. The detailed files are located in the `protocol/`, `pilot/`, and `figures/` directories.

## Appendices

- **Appendix A - Detailed C/K/I/D Scoring Rubric**: `protocol/ckid_rubric.md`
- **Appendix B - Pilot Demonstration and Calculation Example**: `pilot/pilot_design.md`
- **Appendix C - Fixed Self-Reflective TUDOK Evaluation Protocol**: `protocol/evaluator_prompt_HU.md`, `protocol/evaluator_prompt_EN.md`
- **Appendix D - Structured Reporting JSON Schema**: `protocol/reporting_schema.json`
- **Appendix E - Dictionary of Diagnostic Flags**: `protocol/diagnostic_flags.md`
- **Appendix F - Inter-Rater Agreement Protocol**: `pilot/irr_report_template.csv`
- **Appendix G - Robustness and Sensitivity Analysis**: `pilot/prompt_set_template.csv`, `pilot/scoring_template.csv`
- **Appendix H - Mini Pilot Validation Plan**: `pilot/pilot_design.md`
- **Appendix I - Domain-Specific Adaptation**: `protocol/ckid_rubric.md`, `protocol/diagnostic_flags.md`
- **Appendix J - Detailed Example Collection on TUDOK and Factuality**: `examples/`
- **Appendix K - Figure List and Enlarged Versions of the Diagrams**: `figures/`
- **Appendix L - Ethical and Transparency Statement**: see the public paper and validation notes
- **Appendix M - Open Validation and Licensing Note**: `LICENSE.md`
- **Appendix N - GitHub Repository and Open Validation Package**: this repository

## Publication Status

The appendices are pilot-ready, pre-validation materials. Their purpose is to support independent validation, expert review, and the execution of mini pilots.

## Key Limitation

The TUDOK protocol is not a truth-verification engine and not a certification tool. The appendix package supports calibration and audit-preparation use.
